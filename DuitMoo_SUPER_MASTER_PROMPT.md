# SUPER MASTER PROMPT — BUILD DUITMOO IN ANTIGRAVITY

Aplikasi web bernama "DuitMoo" (Personal Budget Planner & Expense Tracker).
Tagline: "Your Money, Your Rules!"
Stack: Laravel 11, Livewire 3, Tailwind CSS, Alpine.js, Chart.js, MySQL (duitmoo), Poppins.
Desain: Original Toy-Brick Gameboard (#FFD54F Yellow, #407BFF Blue, #45C486 Green, #FF6B6B Red, #9B7EDE Purple, #FFF9EB Cream, #263238 Ink).
Perhitungan: Integer Rupiah, 60/30/10 default, floor + exact remainder for emergency.
Roles: User & Admin (Admin restricted from user financial records).
Anti-IDOR policies & strict user isolation.
